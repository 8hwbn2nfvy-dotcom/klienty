# Клиенты

Сайт-агент для поиска клиентов. Выбираешь нишу и город, агент находит заведения на карте, проверяет их сайты и выдаёт список тех, кому нужен сайт или его обновление, с оценкой от 0 до 100.

Агент ничего не отправляет, не пишет писем и не делает макетов. Он только ищет и оценивает.

Значок 🟡 значит: «не проверено на живом сайте, проверь».

## 1. Как пользоваться

**Вход.** Открой адрес сайта и введи пароль. Сайт помнит вход 30 дней. Пароль нигде не хранится, в Render лежит только его хэш (см. шаг 2.3).

**Меню** есть на всех страницах (на телефоне и iPad — кнопка «Меню» справа вверху):

| Пункт | Что там |
|---|---|
| Список | Главная: «Что ищу», кнопка «Найти клиентов» и найденные заведения |
| История | Последние 100 поисков: дата, ниши, города, что искали, чем закончилось (готово / ошибка / отменён) |
| Ниша | Что искать, можно несколько. Сейчас: шиномонтаж, автосервис, автомойка, парикмахерская, салон красоты, стоматология. Отметь плитки → **«Готово»** |
| Город | Где искать, можно несколько. Стартовый — Волгоград. Отметь плитки → **«Готово»** |
| Количество | Сколько лучших заведений показать за один поиск, на все выбранные города вместе: 5, 10, 15, 20, 25, 30, 40 или 50. Нажал число — сохранилось и открылся список |
| Карты | Откуда брать заведения. Работает OpenStreetMap; 2ГИС и Яндекс Карты — «Скоро» |
| Настройки | Оформление (белый, чёрный, графит, песочный, ночной синий) и «Выйти» |

**Что ищу.** Над кнопкой поиска выбери категории: «Создание сайта», «Создание визитки», «Доработка» (можно несколько, «Все» включает три). Это условие поиска: агент отдаёт лучших только из выбранных категорий. Выбор запоминается; список показывает те же категории.

**Поиск.** На главной нажми **«Найти клиентов»**. Под ней появится **«Отменить поиск»**: поиск останавливается, в список ничего не добавляется, в истории он отмечен «Отменён». Появится радар: точки — найденные заведения, счётчик и этапы «ищу заведения → проверяю сайты → считаю оценку» идут от сервера, а не по таймеру. Поиск может занять несколько минут: сайты проверяются не чаще одного запроса в секунду на сайт. Можно уйти на другую страницу и вернуться, поиск продолжится.

Если поиск оборвался (например, Render перезапустился), на главной будет ошибка и кнопка **«Повторить»**.

В окнах «Ниша», «Город» и «Количество» сверху есть **«← Назад»**: возвращает на список, ничего не меняя.

**Список.** Название, категория, оценка, телефон и ссылки на соцсети, мессенджеры и онлайн-запись (нажатие по ссылке открывает её, по строке — карточку); если выбрано несколько городов — ещё и город. Жёлтая пометка «карта 2016» значит: запись на карте не обновлялась больше 3 лет, проверь по телефону, работает ли заведение. Пропущенные скрыты, их показывает переключатель «Показывать пропущенные».

**Карточка** открывается нажатием на строку: адрес, что предложить, из чего сложилась оценка, результат проверки сайта, контакты из карты и ссылка на объект в OpenStreetMap. Кнопки:

- **«1 — беру в работу»** → статус «В работе»;
- **«2 — пропускаю»** → статус «Пропущено»;
- **«Вернуть в „новое“»** — появляется, если статус уже менялся.

С клавиатуры iPad работают клавиши `1`, `2` и `Esc`.

**Повторный поиск** по той же нише и городу не создаёт дублей и не сбрасывает статусы. Карту агент спрашивает не чаще раза в сутки, а в выдачу попадают только заведения со статусом «Новое». Если ничего нового нет, сайт так и напишет.

## 2. Запуск: Supabase и Render

Всё делается в Safari на iPad. Понадобятся два бесплатных сервиса: **Supabase** (база) и **Render** (сам сайт).

### Шаг 2.1. Supabase — новая база (≈10 минут)

1. Открой https://supabase.com/dashboard → войди (кнопка **Continue with GitHub**).
2. Нажми **New project**:
   - **Name**: `klienty`;
   - **Database Password**: нажми **Generate a password**, потом **Copy** и сохрани пароль в Заметках;
   - **Region**: **Central EU (Frankfurt)**;
   - нажми **Create new project** и подожди пару минут.
3. Наверху страницы проекта нажми **Connect** → в разделе **Connection String** выбери **Session pooler** → скопируй строку, которая начинается с `postgresql://`.
4. В этой строке есть кусок `[YOUR-PASSWORD]`. Замени его **вместе со скобками** на пароль из пункта 2, слитно, без пробелов. Было `...:[YOUR-PASSWORD]@...`, стало `...:Abc123xyz@...`. Сохрани строку в Заметках: это `DATABASE_URL`.

🟡 Нужен именно **Session pooler**: обычный «Direct connection» с Render может не подключиться.
🟡 На бесплатном Supabase можно держать 2 активных проекта. Если у тебя уже есть Priz и ещё один, третий создать не даст.
🟡 Бесплатный Supabase ставит проект на паузу, если базой не пользоваться неделю. Тогда сайт покажет «База недоступна». Открой проект в Supabase и нажми **Restore project**.

Таблицы сайт создаст сам при первом запуске (миграции).

### Шаг 2.2. Render — сам сайт (≈15 минут, из них 5–10 ждать)

1. Открой https://dashboard.render.com → войди через GitHub.
2. Нажми **+ New** → **Web Service**.
3. В списке репозиториев выбери **klienty** → **Connect**. Если его нет в списке, нажми **Configure GitHub** (или **Credentials**) и разреши доступ к репозиторию `klienty`.
4. Проверь поля:
   - **Name**: `klienty`;
   - **Language**: **Docker**;
   - **Branch**: `main`;
   - **Region**: **Frankfurt (EU Central)** — рядом с базой;
   - **Instance Type**: выбери **Free** вручную. ⚠️ Render часто сам ставит платный **Starter** — нажми на карточку **Free**.
5. Ниже **Environment Variables** → **Add Environment Variable**. Добавь одну переменную, пароль добавим на шаге 2.3:

   NAME:
   ```
   DATABASE_URL
   ```
   VALUE (строка из шага 2.1.4):
   ```
   postgresql://postgres.xxxx:ТВОЙ_ПАРОЛЬ@aws-0-eu-central-1.pooler.supabase.com:5432/postgres
   ```
   Без кавычек и без пробелов по краям.

6. Раскрой **Advanced** → в поле **Health Check Path** впиши:
   ```
   /api/health
   ```
   **Auto-Deploy** оставь **On Commit** (или **Yes**).
7. Нажми **Deploy Web Service**. Первая сборка идёт около 3–5 минут. Когда появится **Live**, сверху будет адрес вида `https://klienty-xxxx.onrender.com`. Это твой сайт.
8. Проверь тариф: слева **Settings** → раздел **Instance Type** должен показывать **Free**. Если там Starter, нажми **Update** (или **Change**) → **Free** → **Save changes**.

### Шаг 2.3. Пароль (≈3 минуты)

1. Открой адрес сайта. Раз пароль ещё не задан, на странице входа будет форма **«Пароль ещё не задан»**.
2. Придумай пароль (от 8 символов), введи его дважды и нажми **«Получить строку для Render»**.
3. Сайт покажет два блока: **Имя** и **Значение**. В Render открой сервис **klienty** → слева **Environment** → **+ Add Environment Variable** (или **Edit** → **Add**):

   NAME:
   ```
   PASSWORD_HASH
   ```
   VALUE: нажми **«Копировать»** у блока «Значение» на сайте и вставь. Строка начинается с `scrypt$`.

4. Нажми **Save Changes** (или **Save, rebuild, and deploy**). Render перезапустит сайт, это около минуты.
5. Открой сайт снова и войди с новым паролем.

**Где лежит пароль:** только у тебя в голове или в Заметках. В Render лежит хэш, по нему пароль не узнать. Забыл пароль — удали `PASSWORD_HASH` в Render → **Environment**, сохрани, и сайт снова покажет форму «Пароль ещё не задан». После смены пароля все старые входы закрываются.

### Как это работает на бесплатном Render

- Сайт **засыпает после 15 минут** без запросов. Первое открытие после сна — около минуты. Это нормально.
- Если Render перезапустил сайт посреди поиска, поиск помечается ошибкой с кнопкой «Повторить». Найденное до обрыва не теряется.
- Пинг, который не даёт сайту уснуть, пока не ставим. Решим после первой недели работы 🟡.
- 🟡 Адрес `…onrender.com` в России может открываться не у всех провайдеров. Если не открывается без VPN — напиши, перенесём как Priz.

## 3. Как добавить нишу и город

Обе вещи — одна строка в файле [`app/catalog.py`](app/catalog.py). На iPad: открой файл на github.com → значок карандаша (**Edit this file**) → допиши строку → **Commit changes…** → **Commit changes** в `main`. Render сам пересоберёт сайт за пару минут.

**Новый город** — строка в списке `CITIES`:

```python
City("kazan", "Казань", "Казань, Россия"),
```

Первое — короткий код латиницей (любой, но не повторяющийся), второе — как показать на сайте, третье — строка для поиска города в OpenStreetMap.

**Новая ниша** — строка в списке `NICHES`:

```python
Niche("florist", "Цветочный магазин", ('["shop"="florist"]',), _DEFAULT_OFFER),
```

В скобках — теги OpenStreetMap, по которым искать. Нужный тег находится на https://wiki.openstreetmap.org/wiki/RU:Map_features (например, `shop=florist`, `amenity=cafe`, `shop=bakery`). Можно указать несколько тегов через запятую:

```python
Niche("cafe", "Кафе", ('["amenity"="cafe"]', '["amenity"="restaurant"]'), _DEFAULT_OFFER),
```

Если не уверен в теге — пришли мне название ниши, подберу.

## 4. Как перейти с Free на платный тариф Render

Когда поиск станет регулярным, бесплатный сон и перезапуски начнут мешать. Тариф **Starter** не засыпает и стоит около **$7 в месяц** 🟡 (цену проверь на странице тарифов: https://render.com/pricing).

1. Открой https://dashboard.render.com → сервис **klienty**.
2. Слева **Settings** → раздел **Instance Type** → **Update** (или **Change**).
3. Выбери **Starter** → **Save changes**. Render попросит привязать карту, если её ещё нет.
4. Сайт перезапустится, адрес не изменится.

Вернуться на Free — так же, выбрав **Free**.

## 5. Как считается оценка

Правила лежат в [`app/scoring.py`](app/scoring.py), каждое число — константа в начале файла. Пороги стартовые: их надо сверить на первых 10 реальных записях 🟡.

**Категория:**

- сайта нет, но есть 2 и больше канала связи (соцсети, мессенджеры, онлайн-запись) → **«Создание сайта»**;
- сайта нет, только телефон (или один канал) → **«Создание визитки»**;
- сайт есть, но найден хотя бы один признак старой визитки → **«Доработка»**;
- сайт в порядке → в список не попадает.

Ссылка на VK, Instagram, Telegram, Taplink или сервис записи в поле «сайт» на карте считается каналом связи, а не сайтом. Ссылки на 2ГИС, Яндекс и другие каталоги не считаются ни тем, ни другим.

**Свежесть данных карты.** OpenStreetMap в России заполняют добровольцы, часть записей годами не обновляется. Агент смотрит дату последней правки записи и отметки «проверено на месте» (`check_date`). Если обеим больше 3 лет, запись получает −15 баллов и пометку «проверь, работает ли». Заведения, отмеченные на карте закрытыми, в список не попадают. В итоге поиска и в истории написано, на какую дату данные карты у сервера, который ответил; сервер с данными старше недели агент пропускает, если есть свежее.

**Признаки старого сайта** (у каждого свои баллы): сайт не открывается, нет https, нет мобильной версии (`meta viewport`), год в подвале старше 3 лет, очень короткая главная (меньше 600 символов текста), одна страница, битые ссылки.

Сайт не скачивается и не сохраняется: агент открывает главную (таймаут 10 секунд, с переадресациями), проверяет до 3 внутренних ссылок и записывает только признаки. К одному сайту — не чаще одного запроса в секунду. Если сайт не открылся, это «сайт не открывается», а не «сайта нет».

Оценка 0–100 — сумма баллов, в карточке видно каждое слагаемое. Список отсортирован по убыванию оценки.

## 6. Как устроен проект

```
app/
  main.py        страницы и API
  catalog.py     ниши и города
  scoring.py     категории и оценка (константы)
  sitecheck.py   проверка сайта: только признаки
  contacts.py    телефоны, соцсети и мессенджеры из тегов карты
  jobs.py        задача поиска; состояние только в базе
  sources/       источники: osm.py работает, dgis.py и yandex.py — заглушки «скоро»
  store.py       настройки (тема, ниша, город, количество, карты)
  auth.py        вход по паролю, cookie на 30 дней
  migrate.py     миграции базы
migrations/      001_init.sql и следующие; старые файлы не правятся
pages/           HTML страниц
static/          app.css, app.js, значок
tests/           тесты (pytest) с поддельной картой и поддельными сайтами
```

- **Python + FastAPI**, Docker, Render. База — Postgres в Supabase.
- **Миграции:** при старте сайт применяет новые файлы из `migrations/` по порядку и записывает их в таблицу `schema_migrations`. Чтобы поменять таблицы, добавь файл `002_что_меняем.sql`.
- **Источники-адаптеры:** у каждой карты свой класс с методом `search(ниша, город)`. 2ГИС и Яндекс сейчас заглушки, включить их нельзя.
- **OpenStreetMap:** город ищется через Nominatim (результат кэшируется навсегда), заведения — через Overpass API (один и тот же запрос не чаще раза в сутки). Серверов Overpass несколько (`app/config.py`), первым стоит `maps.mail.ru`: с Render основной `overpass-api.de` не подключается. Если сервер не отвечает или его данные старше недели, агент пробует следующий, а в ошибке пишет, что ответил каждый. Каждая пара «ниша + город» — отдельный запрос. Не чаще одного запроса в секунду к каждому сервису. В базе хранятся нормализованные записи со ссылкой на объект OSM, сырой ответ не хранится. Внизу списка и в карточке есть подпись «© OpenStreetMap contributors».
- **User-Agent** во всех внешних запросах: `KlientyAgent/1.0.0 (+https://github.com/8hwbn2nfvy-dotcom/klienty)`.

**Переменные окружения:**

| Переменная | Обязательна | Что это |
|---|---|---|
| `DATABASE_URL` | да | строка подключения Supabase (Session pooler) |
| `PASSWORD_HASH` | да | хэш пароля из формы первого запуска |
| `SESSION_SECRET` | нет | секрет подписи входа; без него выводится из хэша пароля |
| `OVERPASS_URL` | нет | свои серверы Overpass через запятую, по порядку |
| `NOMINATIM_URL` | нет | другой сервер Nominatim |

**Тесты** (нужен Postgres; база очищается!):

```sh
pip install -r requirements-dev.txt
TEST_DATABASE_URL=postgresql://postgres@127.0.0.1:5432/klienty_test python -m pytest -q
```

**Локальный запуск:**

```sh
pip install -r requirements.txt
DATABASE_URL=postgresql://... PASSWORD_HASH='scrypt$...' uvicorn app.main:app --reload
```
